# Екзаменаційна робота: «Сторінка “Світлофор F1”»

**Мета:**
Розширити існуючий проєкт **«Світлофор»**, створений під час семестрової роботи, додавши **захищену сторінку “Світлофор F1”** з окремим компонентом світлофора Формули-1 та синхронізацією з автомобільним світлофором.


## 1. Роут і сторінка

### 1.1. Створити нову сторінку

* Створити компонент сторінки, наприклад: `F1TrafficLightPage`.

### 1.2. Додати роут

* Додати маршрут, наприклад: `/f1-traffic-light` (можна іншу логічну назву).
* Підключити його до існуючого **React Router**.

### 1.3. Обмежити доступ

* Налаштувати, щоб сторінка була **доступна лише для авторизованих користувачів**
  (використати вже наявний у проєкті механізм перевірки авторизації).


## 2. Розширення існуючого контексту / стану

### 2.1. Додати підтримку F1-світлофора

Розширити наявний контекст/стан (наприклад, `TrafficLightContext` або аналогічний), додавши:

* стан **автомобільного світлофора** (як у вихідному проєкті);
* стан **світлофора F1**;
* прапорець / логіку, коли **кнопка керування F1-світлофором має бути заблокована**.

### 2.2. Забезпечити синхронізацію

Логіка в контексті (або в окремому шарі стану) має гарантувати узгоджену роботу:

* коли **автомобільний світлофор** показує **зелене світло**,
  – світлофор F1 має бути в стані **«Стоп»**;
  – кнопка керування F1 має бути **заблокована**;
* в інших станах автомобільного світлофора кнопка F1 може бути **активною**.

---

## 3. Компонент світлофора Формули-1

### 3.1. Створити новий компонент

* Створити компонент `F1TrafficLight`, який відображає щонайменше два стани:

  * **«Стоп»** (червоне світло);
  * **«Старт»** (зелене світло).

### 3.2. Зміна стану

Реалізувати зміну стану світлофора F1:

* **автоматично** — кожні **10 секунд**;
* **вручну** — за допомогою кнопки, яку може натиснути користувач.

### 3.3. Обмеження для кнопки

Якщо автомобільний світлофор показує **зелене світло**:

* стан F1-світлофора має бути примусово **«Стоп»**;
* кнопка керування F1-світлофором має бути **заблокована** (`disabled`).


## 4. Оновлення UI

### 4.1. Відображення світлофорів

На сторінці `F1TrafficLightPage` необхідно:

* Відобразити **автомобільний світлофор** з текстовим або візуальним описом поточного стану.
* Відобразити **світлофор F1** (компонент `F1TrafficLight`).
* Додати **кнопку** для керування F1-світлофором:

  * зрозумілий текст на кнопці;
  * чіткий стан: **активна / заблокована**;
  * при блокуванні — коротке пояснення, наприклад:
    *«Не можна змінювати, коли авто-світлофор зелений»*.

### 4.2. Оформлення

* Зробити охайний, логічний лейаут сторінки.
* Використати **Tailwind** / **DaisyUI** (якщо вже застосовуються в проєкті).


## 5. Навігація

### 5.1. Пункт у меню

* Додати до навігації (наприклад, у `Navbar`) пункт **«Світлофор F1»**, який веде на `/f1-traffic-light`.

### 5.2. Умовне відображення

* Налаштувати, щоб цей пункт меню був **видимий тільки для авторизованих користувачів**.
